## 🚀 Release Process

### 1. Pre-Release Preparation

```bash
# 1. Create feature branch for version updates
git checkout -b release/v2.6.0

# 2. Update all version references (see checklist above)

# 3. Update documentation and changelogs

# 4. Commit version updates
git add .
git commit -m "chore: Bump version to v2.6.0 (GA release)"

# 5. Push and create PR for review
git push origin release/v2.6.0
gh pr create --title "Release v2.6.0 (GA)" --body "First production release..."
```

### 2. Tag and Trigger Build

```bash
# After PR is merged to main
git checkout main
git pull origin main

# Create GA release tag (NO -beta suffix!)
git tag v2.6.0

# Push tag to trigger GitHub Actions
git push origin v2.6.0
```

### 3. GitHub Actions Workflows

The `v2.6.0` tag will trigger:

- ✅ **Docker Build** (`.github/workflows/docker-publish.yml`)
  - Multi-arch build (AMD64/ARM64)
  - Push to Docker Hub: `markotrapani608/redis-acl-builder:v2.6.0`
  - Auto-tag as `:latest`, `:2.6`, `:2`

- ✅ **Desktop Builds** (`.github/workflows/build-desktop.yml`)
  - macOS ARM64 + Intel x64 DMG installers
  - Windows NSIS installer
  - Linux AppImage
  - Auto-publish to GitHub releases with release notes
  - **Will show as "Latest Release" (not pre-release!)**

### 4. Post-Release Verification

```bash
# Verify GitHub Release was created
gh release view v2.6.0

# Verify Docker image was published
docker pull markotrapani608/redis-acl-builder:latest
docker pull markotrapani608/redis-acl-builder:v2.6.0

# Check GitHub UI shows "Latest" badge
open https://github.com/markotrapani/redis-acl-builder/releases

# Verify auto-update metadata is correct
curl -sL https://github.com/markotrapani/redis-acl-builder/releases/download/v2.6.0/latest-mac.yml
```

Release is considered successful when:

- ✅ All GitHub Actions workflows pass
- ✅ GitHub release shows "Latest" badge (not "Pre-release")

- ✅ Desktop installers downloadable for all platforms
- ✅ Auto-update works from v2.5.0-beta → v2.6.0
- ✅ All documentation is updated and accurate
- ✅ No critical bugs reported within 48 hours
