## 🔧 Optional: Enable Code Signing Now

**If you already have Apple Developer account:**

1. **Add GitHub Secrets:**
   - Go to: https://github.com/markotrapani/redis-acl-builder/settings/secrets/actions
   - Add: `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID`

2. **Update workflow:**

   Edit `.github/workflows/build-desktop.yml` line 105:

   ```yaml
   # Change from:
   CSC_IDENTITY_AUTO_DISCOVERY: false

   # To:
   CSC_IDENTITY_AUTO_DISCOVERY: true
   APPLE_ID: ${{ secrets.APPLE_ID }}
   APPLE_APP_SPECIFIC_PASSWORD: ${{ secrets.APPLE_APP_SPECIFIC_PASSWORD }}
   APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
   ```

3. **Commit and push:**

   ```bash
   git add .github/workflows/build-desktop.yml
   git commit -m "ci: Enable macOS code signing and notarization"
   git push origin main
   ```

**Next build will be signed and notarized!**
